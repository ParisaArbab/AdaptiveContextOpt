# Phase 6 — Explicit stages and bounded routing

Added EvidenceStage(sketch, graph, method_full), complete-package graph inspection, a shared logical-spend session, fixed L1-plus-graph control, and an experimental adaptive router. Existing Full, Fixed L1, Highest Suspicion and V2 engines remain intact. The only universal backend change extracts the unchanged legacy identity into an override hook; graph requests add stage, graph, package and config fingerprints. Existing exact-payload journal/cache, durable paid counters, physical caps and unresolved-usage rejection are reused.

The wire parser for one graph verdict reuses the single-verdict Full parser. This does not change the scientific stage: graph observations project to level 1, and only actual method_full observations project to historical level 2. Graph evidence may contain neighbors absent from method_full and omit target code; these are distinct evidence sets. RRF has no automatic Full bonus. Prior ordering stabilizes ties and unverified candidates.

The untrained priority is (0.35*suspicion + 0.30*reported_uncertainty + 0.20*adjacent_closeness + 0.15*evidence_novelty) times a remaining-budget factor, divided by predicted cost. Adjacent closeness uses the current ranking's maximum adjacent gap as scale. Neither raw scores nor this priority are probabilities or calibrated marginal gains. The fixed graph control uses prior order. Adaptive actions have per-stage caps, cheap top-k/uncertainty gates, strict reservation and complete L1-first admission. An infeasible graph package can fall back to Full if independently affordable. Options, rejected packages, estimates, reservations and selected actions are recorded before revealing responses; actual cost appears only afterwards.

Validation: 38 GRAFT tests plus 41 existing universal tests passed (79 total). Eight new stage/controller tests cover exact resume reuse, stage projection, logical/physical limits, changed evidence, paid malformed JSON, unknown usage, decision-time feature separation and provider counter violations. Synthetic provider calls are not real model calls. No GRAFT fault-localization advantage was measured.

Decision: keep the router experimental, BM25 as the default evidence control and topology opt-in pending genuine dense/sparse vectors and independent inference. Build a reproducible CLI and small-run resource profiles next; do not train a utility model on these fixtures.
