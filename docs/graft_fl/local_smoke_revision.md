# Real-model compatibility revision

The first local Llama3.1 8B run on the existing Time-1/Lang-1 development checkouts exposed failures that synthetic tests could not establish: some two-candidate L1 responses omitted one ID; some graph responses emitted long explanation arrays and exhausted the 160-token output limit; the equal-budget Full control stopped under a 24K budget because conservative reservations require headroom. Math-1 was rejected before inference for a source/CSV span mismatch. The complete original run is retained, including all unsuccessful arms.

Graph verdict v2 explicitly requests a short object with string explanations and missing-evidence fields. The graph parser rejects non-string fields after charging the paid request; it does not stringify arrays into apparently valid observations. The exact prompt and version change invalidate graph-response reuse. Legacy L1 and Full prompt/parser behavior is preserved. One focused test checks paid rejection of non-string graph fields; the selected regression command passed 189 tests.

The follow-up configuration uses single-candidate L1 calls, equal 32K policy budgets, unchanged model digest/context/output-per-candidate/fusion/candidate pools and short graph verdict v2. It has its own 60K physical-token / 30K-per-bug / 100-new-request caps. Only exact unchanged Full requests may reuse the initial cache. New batches and graph contexts need new responses. These changes were chosen from response validity and reservation diagnostics, not gold-rank optimization. Because several settings changed, quality differences between rounds are not isolated controller or prompt effects.

The A100 smoke configuration/protocol now starts with these conservative compatibility settings. 16K/24K sensitivity conditions remain available; the original phase-7 report preserves its earlier 24K planning decision. An A100 experiment still requires its own official buggy checkouts, reliable evidence and provider checks. Local trigger-test development runs are not new observed-failure or held-out experiments. The three preselected independent-feasibility bugs are not silently replaced by these development cases.

Measured results, provider counters, source hashes, unsuccessful attempts and reproducible audit commands are preserved in `reports/graft_fl_local_real_smoke_2026_11_05/`. This compatibility fix does not establish fault-localization superiority, real BGE-M3 support or A100 hardware performance.
