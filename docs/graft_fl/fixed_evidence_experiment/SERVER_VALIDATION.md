The 100-defect core and disjoint 100-defect extension are frozen before new generation. See the [server runbook](../../../SERVER_RUNBOOK.md) for operations and [selection manifest](../../../configs/graft_server/selection-v1.json) for exact revisions and ranking identities.

## Executed checks

- The pinned manifests regenerated byte for byte from the pinned local Defects4J and FlexFL Git objects.
- The audited tokenizer extension compiled against the exact Ollama source on the Mac and in a local Debian 12 Linux ARM64 container using Go 1.24.1 and GCC 12. The Linux CPU CMake build and install completed. The network-disabled Linux tokenizer and the Mac source build each reproduced exact rendered bytes and token IDs for all 72 archived requests using vocabulary-only loading. This was an offline tokenizer check with zero generation calls.
- An initial Linux container used a legacy compiler that could not compile the pinned Ollama C++ sources. The check passed with GCC 12, as specified in the runbook.
- The unsupported Mac preflight produced a blocked host inventory and a 200-row disposition, with no dispatch. Loopback and synthetic checks exercise batch gating, journal reconciliation and paid or unresolved usage.
- SHA-256 revalidation matched all 88 archived Lang-54/Math-80 files and the three frozen 12-defect design files. The archived JxPath-14 reproduction and the Mac scientific implementation were retained.
- The full workspace test run passed 340 tests. Three pre-existing failures also appear in the prior coordinate-gate log: Agent4SR format finalization and two legacy pipeline tests that reference the absent `scripts/run_pipeline.sh`.

The actual server was not contacted. Its driver, CUDA build, serving/tokenizer certificate, full A100 offload, authentic trigger reproductions, per-defect resource inventory, admission counts and experimental outcomes require the runbook commands on that host. Project-specific blockers may include upstream SHA access, missing exact build dependencies, ambiguous or offset coordinates, official adapter changes to buggy production bytes, unavailable offline labels, or mandatory evidence overflow.
