# Phase 7 — Reproducible execution and development report

Added a serial GRAFT CLI and shell entry point using the existing adapters, candidate preparation, providers, durable request store, legacy controllers and fusion implementations. Configuration explicitly separates the benchmark from evidence-selection controls. Immutable manifests pin source/data/code/resource hashes; all saved arms and prepared inputs are validated before new paid actions on resume. Failed candidate preparation remains in every configured policy's operational denominator. Labels are read only after collection. Reports distinguish missing labels, incomplete attempts, matched cohorts, logical verification tokens and physical provider usage.

Added reusable archive diagnostics and English report regeneration with five PNG/SVG figures, metric/cost/feasibility tables and consumed-source checksums. The final archive pass uses the final common renderer across relevance, path and repair variants. No historical inference is repeated. Optional BGE export validates complete batches; tokenizer resource identity excludes large model-weight files. Graph lookup is immutable, path costs must be nonnegative, graph verdicts require explicit uncertainty, and source-root configuration remains repository-relative.

Validation: 188 tests passed, including 47 newly added GRAFT tests and 141 existing tests. The command and full output are preserved in `reports/graft_fl_development_2026_11_05/validation/software_tests.txt` and `verification.json`. No unrelated pre-existing failure occurred in this selected suite; the entire repository's external integration suite was not run. A separate saved Java/Python synthetic execution completed all 14 configured arms, using ten simulated requests and 3,088 simulated provider tokens; resume added zero requests. These are software checks, not independent bugs or real-model findings.

Measured archive diagnostics: 97 prepared inputs yielded 13,794 nodes with zero candidate AST parse errors. At 4,096 byte-proxy units, relevance alone had 93 feasible first-prior-target packages and 259 missing observable prerequisites across 62 packages. Standalone repair retained 93 feasible packages and removed all observable gaps. Paths retained 90; paths plus repair retained 88. These structural outcomes do not measure localization quality. Exact results at all three input allowances and strict/historical metrics are in the report snapshot. All 388 directly consumed archive input/result/label/manifest files were rechecked unchanged.

Cost-based planning: the 93 jointly completed archived arms averaged 12,267.86 tokens for Full, 10,453.75 for Fixed L1 and 10,944.45 for V2 Utility. Proposed policy budgets are 16K/24K/32K, primary 24K; context starts at 8,192 independently. The archived policy budget was 120K. A separate high-budget Full reference is not an equal-budget comparison. Model families, sizes, digests, endpoints, context and physical caps remain configurable.

Decision: default to the simple BM25 evidence control plus observable repair for the next exploratory test, retain paths and real dense topology as explicit ablations, and keep adaptive routing experimental. No real model/encoder run was performed and no advanced-policy advantage was established. Preselected Lang-54/Math-80/Closure-61 feasibility is prepared, not executed: the new official checkouts, failure logs and manifest are unavailable here, and the user's A100 is external. Exact commands and requirements are in `docs/GRAFT_FL.md` and `configs/graft_feasibility_protocol.json`.
